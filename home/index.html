about ➰

The rise in theft, crimes, and public security threats demands smarter surveillance. Traditional CCTV systems only record footage, requiring manual review. Our project introduces a real-time AI-powered face recognition system that can detect and identify known criminals instantly using existing camera infrastructure—preventing crimes before they escalate.

How we Solved it

Captures live video from cameras (e.g., laptop webcam)
Detects and matches faces using AI/ML models
Identifies known criminals (from a mock or real database)
Sends real-time alerts to nearby police stations with location
Displays past criminal history and real-time match data on a dashboard
